# א.ס מיזוג אוויר — نسخة التصميم

هذه نسخة محلية لمراجعة الهوية البصرية وتجربة الاستخدام. اللغة الافتراضية العبرية، مع العربية والإنجليزية واتجاه RTL/LTR مناسب. الهاتف +972 52-950-4011 والخدمة لجميع المدن في إسرائيل.

## المعاينة

شغّل `npm run dev` من هذا المجلد ثم افتح http://127.0.0.1:5173/. يوجد ملف `تشغيل الموقع.cmd` في مجلد الشركة لتشغيل المعاينة بالنقر المزدوج. يحتاج Node.js 22.13 أو أحدث.

## تجهيز الاستضافة الإسرائيلية

أصبح `npm run build` ينشئ حزمة Node.js المستقلة في `dist/standalone`، ويمكن تشغيلها محليًا عبر `npm start`. يتوفر `npm run build:node` كاسم صريح للمسار نفسه. تعليمات رفع الحزمة وإعداد التطبيق والنطاق موجودة في [دليل النشر](DEPLOY-ISRAEL.md). يلزم اختيار خطة تدعم تطبيق Node.js مستمرًا (Node.js 22.13 أو أحدث)، وليس استضافة ملفات ثابتة فقط. لم تتم إضافة الدفع أو Zap.

## الصفحات

- `/`: الرئيسية، منتجات مقترحة، خدمات، اختيار حسب المساحة، أسئلة شائعة وتواصل.
- `/products`: كتالوج، بحث، تصفية حسب العلامة والمساحة، ترتيب السعر ومقارنة حتى 3 موديلات.
- `/products/[slug]`: صور ومواصفات ومزايا وطلب عرض سعر ومعلومات التركيب والضمان.
- `/services`: التركيب والتنظيف والصيانة والتشخيص والإصلاح.
- `/about`: نبذة الشركة وطريقة العمل.
- `/contact`: الهاتف وواتساب ومناطق الخدمة ونموذج تجهيز طلب.
- `/faq` و`/policies`: معلومات واضحة للزائر.

## البيانات التجريبية

الدليل يحتوي ستة موديلات واقعية من Tadiran وElectra لتوضيح التصميم. الأسعار أمثلة وليست أسعار الشركة. حالة التوفر غير مؤكدة؛ يظهر للزائر طلب تأكيدها. صور المكيفات صور السلسلة وليست توثيقًا لكل رقم موديل. لا تعرض النسخة وعودًا تجارية مختلقة عن سنوات الخبرة أو عدد العملاء أو ضمان موحد.

المواصفات والصور النموذجية مأخوذة من صفحات المصنع العامة، وروابط المصدر موجودة في `app/catalog-data.ts` وتظهر في صفحة التفاصيل:

- https://www.tadiran-group.co.il/product/alpha-pro-inv-140ng/
- https://www.tadiran-group.co.il/product/alpha-pro-inv-240ng/
- https://www.tadiran-group.co.il/product/tadiran-alpha-pro-inv-340ng/
- https://www.tadiran-group.co.il/product/alpha-pro-inv-370ng/
- https://www.electra-air.co.il/product/electra-a-inverter-170/
- https://www.electra-air.co.il/product/electra-a-inverter-240/

الصورة الرئيسية صورة أجواء مولدة، لا توثق مشروعًا منفذًا للشركة أو موديلًا بعينه. استخدام صورة الأجواء في تفاصيل المنتج مميز بوضوح. الشعار الأصلي محفوظ في مجلد الشركة، وتستخدم النسخة صورة منه.

## ما يعمل الآن

الكتالوج والتصفية والمقارنة والقوائم والتبديل بين اللغات وتبويبات المنتجات والأسئلة الشائعة. نموذج التواصل يتحقق من البيانات ويعرض الطلب للمراجعة، ثم يجهز رسالة واتساب. لا يرسل النموذج البيانات ولا يخزنها؛ الإرسال يتم من واتساب بعد مراجعة الزائر. روابط الاتصال وواتساب توجه للرقم الفعلي للشركة.

## لوحة الإدارة

افتح `/admin` بعد تشغيل الموقع، وسجّل الدخول ببيانات المدير التي تضبطها في إعدادات تطبيق Node على الاستضافة. من اللوحة يمكنك إضافة الموديلات وتعديل الأسعار والمواصفات والتوفر والصور، وتغيير الهاتف وWhatsApp ومناطق الخدمة والشعار وصورة الواجهة. في التطوير المحلي يعمل التخزين على الملفات؛ وللإنتاج تحفظ بيانات اللوحة في Supabase PostgreSQL والصور في Supabase Storage. راجع [دليل إعداد Supabase](SUPABASE-SETUP.ar.md) قبل نشر التطبيق. لا تشمل هذه المرحلة الطلبات أو الدفع أو ربط Zap.

## التصميم والتقنية

واجهة React/TypeScript على Vinext، مع CSS مخصص وأيقونات Lucide. الخطوط مستضافة محليًا: Heebo للعبرية، Noto Sans Arabic للعربية، Manrope للإنجليزية. الصور المستخدمة مضغوطة بصيغة WebP. الحركات خفيفة وتحترم إعداد تقليل الحركة. واجهة الهاتف لها قائمة خاصة وبطاقات مقترحة قابلة للسحب.

الملفات الأساسية: `app/site.tsx` للترويسة والتذييل واللغة، `app/experience.tsx` للكتالوج والمنتجات والرئيسية، `app/company-pages.tsx` لصفحات الشركة، `app/globals.css` للهوية والتجاوب، و`app/catalog-data.ts` للبيانات.

## التحقق

`npm run typecheck` لفحص الأنواع، و`npm run build` للتحقق من البناء. مع تشغيل المعاينة، `npm run test:design` يفحص الصفحات عبر اللغات الثلاث بعروض 320 و390 و768 و1440 بكسل، مع مقارنة الصور وحالات الفراغ والتصفية ومقارنة الموديلات وتبويبات المنتج وتجهيز الطلب والقائمة والهاتف واتجاه اللغة. النتائج والصور في `qa/`.

يوجد دعم اختياري لتصفية الكتالوج عبر WebMCP عند توفره في المتصفح؛ واجهة التصفية تعمل بدونه. لم يتوفر متصفح يدعم WebMCP الحقيقي في هذه الجلسة، لذلك لا يُعد هذا التكامل معتمدًا للنشر.

## المرحلة التالية

بعد مراجعة التصميم والموافقة عليه: إدخال الكتالوج والأسعار والمخزون والصور التجارية النهائية، توثيق السياسات الفعلية، ثم دراسة Zap والدفع عبر Visa/Bit والطلبات والشحن والإدارة واختيار نطاق .co.il. أُضيف تجهيز حزمة Node للاستضافة، لكن الموقع لم يُنشر خارج الجهاز.
